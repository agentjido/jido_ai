These checked examples use the current Jido AI public contract. Each feature
keeps its source and detailed guide in one folder. Its tests live in the
matching `test/examples/08_planning` folder.

| Feature | Guide | Tests |
| --- | --- | --- |
| `08_01_planning` | [08_01 — Planning Actions and capability](08_01_planning/README.md) | [08_01_planning_test.exs](../../test/examples/08_planning/08_01_planning/08_01_planning_test.exs) |

```sh
mix test test/examples/08_planning --include example --seed 0
```

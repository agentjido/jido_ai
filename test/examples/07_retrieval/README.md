# Retrieval example tests

These tests run the source examples in `examples/07_retrieval`. They use the
`:example` tag and do not run with the normal `mix test` command.

| Feature guide | Tests |
| --- | --- |
| [07_01_memory](../../../examples/07_retrieval/07_01_memory/README.md) | [07_01_memory_test.exs](07_01_memory/07_01_memory_test.exs) |

Run this group from the repository root:

```sh
mix test test/examples/07_retrieval --include example --seed 0
```

See [all example tests](../README.md).
